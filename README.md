# 🎬 Netflix Data Analysis Project

## 📌 Overview

This project focuses on analyzing Netflix movies and TV shows data to uncover trends, patterns, and insights.
The analysis is performed using Python for data processing and visualization, along with Power BI for interactive dashboard creation.

---

## 🚀 Objectives

* Perform data cleaning and preprocessing
* Analyze content distribution (Movies vs TV Shows)
* Identify popular genres and trends
* Study content growth over the years
* Visualize insights using charts and dashboards

---

## 🛠️ Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Power BI

## 📊 Key Analysis Performed

* Movies vs TV Shows distribution
* Top genres on Netflix
* Content added over the years
* Country-wise content distribution
* Duration analysis

---

## 📈 Power BI Dashboard

The project includes an interactive Power BI dashboard with:

* Content distribution visuals
* Yearly trends
* Genre analysis
* Country-wise mapping
* KPI cards for quick insights

---

## 🔍 Key Insights

* Netflix platform contains more Movies compared to TV Shows
* Significant growth in content after 2015
* Drama and Comedy are among the most popular genres
* USA, India, and UK contribute the most content

## ▶️ How to Run the Project

1. Clone the repository

```
git clone https://github.com/your-username/Netflix-Data-Analysis.git
```

2. Navigate to project folder

```
cd Netflix-Data-Analysis
```

3. Install dependencies

```
pip install -r requirements.txt
```

4. Run the project

```
python main.py
```
